## Provenance

Derived from OSSM project source: the base geometry originated as an outline
projection taken from a STEP file in the OSSM repository, converting the
default `OSSM - Body - Cover` into a PCB enclosure. The original geometry
remains the copyright of the OSSM project contributors.

Upstream: <https://github.com/KinkyMakers/OSSM-hardware>

## Modifications by armpitMFG

  - Converted the default body cover into a PCB enclosure with cable routing
  - Interlocking interface to help prevent fluid intrusion
  - Capacitor support up to 18mm diameter
  - Magnetic faceplate option with 10x2mm magnet retention ridges
  - Optional covered RJ45 port variant
  - See the `Updates` section of `README.md` for the full revision history
